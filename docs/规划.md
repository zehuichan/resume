# 陈泽辉简历 · 规划

一份给招聘方看的中文技术简历：HR 和面试官在浏览器里读、打印或存 PDF，我自己把内容分段贴进招聘平台。站点是 GitHub Pages 上的静态页，没有后端。

| 页面 | 地址 | 给谁 |
| --- | --- | --- |
| 简历 | `/#/` | HR、面试官：读、打印、存 PDF |
| 线上版 | `/#/online` | 我自己：按招聘平台的栏目分段复制 |

视觉和交互的细节在 [DESIGN.md](../DESIGN.md)；接手改代码先读 [AGENTS.md](../AGENTS.md)。

## 产品基调

手感照 Linear，拆成 14 条规矩。A4 简历纸面是例外：它按打印排版，保留自己的字号和青绿强调，下表只管工具界面（底部工具条、线上版、快捷键清单）。

| # | 规矩 | 怎么算做到 | 落在哪 |
| --- | --- | --- | --- |
| 1 | 快 | 首屏 JS ≤ 72 KB、CSS ≤ 19 KB（gzip），部署前检查；网页字体不挡首屏；复制是本地操作，按钮上直接给结果，没有加载状态 | F3、F6，技术方案「速度预算」，T3 |
| 2 | 键盘优先 | 一张命令表；悬停提示、`?` 清单、按键监听都从它读；工具条上能点的都有按键 | F5，技术方案「命令表」，T2 |
| 3 | 有主见 | 没有设置项：明暗跟系统，没有主题开关；只有一份简历，不让访客选版本 | F3，T1 |
| 4 | 不打断 | 没有 `alert`、确认框、引导浮层；失败在按钮原地说，并把正文选中方便手动复制 | F2、F6，T1 |
| 5 | 颜色只表达含义 | 中性灰阶；主色只给主按钮、链接、聚焦、文字选区；当前页用灰底 | F3，DESIGN.md「Colors」，T3（lint） |
| 6 | 内容能直接给研发和 Agent 用 | 简历每个栏目有固定链接 `#/#<栏目>`；整份简历一键复制为 Markdown | F6，T4、T5 |
| 7 | 接入不用手抄配置 | 不适用 | 「不做」 |
| 8 | 一套规则 | 简历、线上版、Markdown 三个出口读同一份数据 `src/views/classic/data`，不各存一份 | F1、F2、F6，技术方案「数据」 |
| 9 | 项目本身好上手 | `pnpm install && pnpm dev` 就能跑；AGENTS.md 写着这些规矩和改需求的流程 | 技术方案「上手」，AGENTS.md |
| 10–14 | 智能体体验 | 不适用：站点没有 Agent 写入的对象 | 「不做」 |

## 功能

### F1 简历

**做什么**：一张 A4 纸面，依次是个人信息、指标、个人优势、专业技能、工作经历、项目经历、其他项目、开源经历、教育背景。内容全来自 `src/views/classic/data/resume.ts`，工作年限按 `experienceStartYear` 自动算。

**验收**：

- 改数据文件，简历、线上版、Markdown 同时变，不用改页面。
- 归档的项目（`archived`）不单独列出：简历的「其他项目」和 Markdown 都不列，它的内容已经折进对应公司的业绩行。
- 屏幕上的纸面跟系统明暗走，打印永远白纸（见 F4）。

**不做**：在线编辑、多套模板、按岗位切换内容。

**页面**：`/#/`。

### F2 线上版

**做什么**：按招聘平台的栏目把简历拆成复制块：个人优势；每段工作经历的内容、业绩、技能标签；每个精选项目的内容和业绩；教育背景。顶部只写「项目 N · 工作经历 M」。

**验收**：

- 每块右上角「复制」，成功变「已复制」，1.6 秒后复原。
- 剪贴板不可用时按钮变「复制失败」（红字），屏幕阅读器读出原因和下一步，正文自动全选，`Ctrl C` 就能复制；不弹框。
- 页面上没有「点这里复制」之类的说明。

**不做**：直接投递到招聘平台、按平台字数限制自动截断。

**页面**：`/#/online`，每个复制块右上角的「复制」。

### F3 底部工具条

**做什么**：全站唯一的浮层，依次是「简历」「线上版」→ 竖线 →「复制为 Markdown」→ 键盘图标（打开快捷键清单）。

**验收**：

- 当前页用灰底（`selected`），不用主色。
- 悬停 300ms 或键盘聚焦时出提示：命令名加按键。
- 窄屏（< 640px）是底部通栏，两页切换平分宽度，不显示键盘图标；宽屏停靠右下角。
- 没有主题开关；打印时隐藏。

**不做**：主题、字号、语言等设置项；顶部导航栏。

**页面**：两页右下角；「简历」「线上版」「复制为 Markdown」、键盘图标。

### F4 打印

**做什么**：在简历页按浏览器的 `Ctrl P` 打印或存 PDF。

**验收**：A4 分页不截断条目；强制白纸深字，深色主题不漏进打印；最小字号 9pt；工具条和栏目标题后的 `#` 不打印。

**不做**：站内「打印」「下载 PDF」按钮（浏览器已经有）、服务端生成 PDF。

**页面**：`/#/`，按 `Ctrl P`。

### F5 键盘

**做什么**：一张命令表管全站按键。

| 分组 | 命令 | 按键 | 什么时候能用 |
| --- | --- | --- | --- |
| 跳转 | 去简历 / 去线上版 | `G R` / `G O` | 一直 |
| 线上版 | 下一段 / 上一段 | `J` / `K` | 在线上版 |
| 线上版 | 复制这一段 / 不选这一段 | `C` / `Esc` | 在线上版 |
| 通用 | 复制为 Markdown | `M` | 一直 |
| 通用 | 全部快捷键 | `?` | 一直 |

**验收**：

- `?` 打开快捷键清单，按分组两列，当前页用不了的行置灰；`Esc` 或点外面关掉，清单开着时别的按键不响应。
- 线上版：没选中时 `J` 从第一块开始、`K` 从最后一块开始；到头停住不绕回；选中的块正文变灰底并滚进视野。
- 在输入框里打字、带 `Ctrl` / `Alt` / `⌘` 的组合键都不触发。
- `G` 后 1.5 秒内按第二键才算跳转。

**不做**：命令面板（`Ctrl K`），见「不做」。

**页面**：任意页按 `?`；工具条键盘图标。

### F6 固定链接和复制为 Markdown

**做什么**：

- 简历的每个栏目标题是固定链接：`#/#summary`（个人优势）、`#/#skills`、`#/#experience`、`#/#projects`、`#/#more-projects`、`#/#open-source`、`#/#education`。锚点是固定的英文 id，栏目改中文名不失效。
- 「复制为 Markdown」把整份简历转成 Markdown：`#` 姓名，`##` 栏目，精选项目 `###` 带链接和「项目背景 / 核心工作 / 项目成果 / 项目收获」，`==高亮==` 转成加粗。

**验收**：

- 打开带锚点的地址，栏目滚到距顶 16px；切换页面回到顶部，浏览器后退回到原位置。
- Markdown 的栏目顺序和简历页一致，不单独列归档项目；复制失败时按钮原地说「复制失败」。

**不做**：每个项目单独的固定链接（见「不做」）、导出 Word / JSON。

**页面**：`/#/` 栏目标题（悬停出现 `#`）；工具条「复制为 Markdown」，或按 `M`。

## 竞品

| 竞品 | 照学 | 要改 | 不做 |
| --- | --- | --- | --- |
| BOSS 直聘等招聘平台的在线简历 | 按平台栏目分段（线上版的分段照它来） | 平台里只能一栏一栏手填 → 线上版每段一键复制 | 投递、职位匹配 |
| 超级简历、WonderCV | A4 模板、打印成 PDF | 靠模板编辑器和设置项 → 不加设置，内容只改数据文件 | 在线编辑器、模板市场 |
| Notion、飞书文档里的简历 | 每节有链接、能复制为 Markdown | 页面重、首屏慢 → 静态页加体积预算 | 评论、协作 |

手感（命令表、`?` 清单、`G` 跳转、中性灰阶、失败原地说）照 Linear。

## 不做

| 不做 | 原因 |
| --- | --- |
| 命令面板 `Ctrl K` | 全站 8 条命令，`?` 清单一屏装得下；弹层组件会让首屏 JS 多约 45 KB |
| 乐观更新、撤销提示条、`Ctrl Z` | 没有会改数据的操作；复制不需要撤销 |
| 骨架、转圈 | 没有接口请求，页面一次渲染完 |
| 主题开关等设置项 | 规矩 3：明暗跟系统就够 |
| 右键菜单 | 没有列表和树；浏览器自己的右键菜单（复制、打印）留着 |
| 时间按远近写 | 简历里的时间是任职区间（`2025.09 - 至今`），不是事件时间 |
| 每个项目单独的固定链接 | 项目名会改，按名字生成的锚点会失效；链接停在栏目这一级 |
| 首屏、切换页面等的毫秒数预算进 CI | 静态站的首屏主要看传输体积；CI 机器上测毫秒抖动大。改用体积预算，毫秒数本地实测记一次（本地预览首次绘制约 0.1 秒） |
| Agent 接入、令牌、Agent 工具和契约测试（规矩 7、10–14） | 没有 Agent 写入的对象；Agent 要读简历，用 F6 的 Markdown |
| API 和权限（规矩 8 的 API 部分） | 静态站，没有后端 |
| 种子数据、开发环境登录（规矩 9 的一部分） | 没有登录，数据就是仓库里的简历 |
| 单独的 HTML 原型 | 页面本身就是原型，功能写「页面：」指向真页面 |

## 技术方案

### 数据

`src/views/classic/data` 是唯一数据源。简历页直接渲染；线上版在 `views/online/index.vue` 里拼成复制块；Markdown 由 `src/shared/lib/resume-markdown.ts` 生成。三处共用 `src/shared/lib/resume-sections.ts` 的取数：基本信息一行、指标、精选项目、其他项目（非精选、非归档，按时间排）。

### 命令表

- `src/shared/commands/commands.ts`：表本身，每条有 id、名字、分组、按键。
- `src/shared/commands/shortcuts.ts`：纯函数 `matchShortcut`，按表匹配按键，处理 `G` 两键序列、`Esc`、`?`，打字和组合键不匹配。
- `src/shared/commands/use-commands.ts`：`useCommand(id, run)` 在组件挂载时登记处理函数、卸载时撤掉，「能不能用」就看有没有登记；`useShortcutListener` 在工具条上挂一个 `keydown` 监听，快捷键清单开着时暂停。
- 悬停提示 `command-tooltip.vue` 和快捷键清单 `shortcut-list.vue` 都按 id 从表里读名字和按键。

### 复制

`src/shared/lib/clipboard.ts` 先用 Clipboard API，失败再用 `execCommand('copy')`。`src/shared/composables/use-copy-feedback.ts` 记最近一次的结果，按钮显示「已复制」或「复制失败」；线上版失败时把正文全选。

### 明暗

`index.html` 里的首帧脚本按系统偏好给 `<html>` 加 `dark`，避免闪白；`src/shared/composables/use-theme.ts` 跟随系统切换。早先版本存在本地的主题选择不再读取。

### 速度预算

- `scripts/check-budget.mjs`：读 `dist/index.html` 引用的 JS 和 CSS，加上最重的那张页面（`classic-*` 或 `online-*`），按 gzip 计；超出就退出码 1。
- 预算：JS 72 KB、CSS 19 KB；现在 62.7 KB / 15.7 KB。
- `.github/workflows/deploy.yml`：测试 → 构建 → 预算，任何一步失败都不发布。
- 悬停提示只用 CSS、快捷键清单用浏览器自带的 `<dialog>`：弹层组件库会把 floating-ui 和 Vue 的 Teleport、Transition 带进首屏的公共包。
- 网页字体用 `media="print"` 加载、到了换成 `all`：连不上 Google 时，阻塞加载会白屏约 30 秒。

### 上手

```bash
pnpm install
pnpm dev          # 本地开发
pnpm test:run     # 单元测试
pnpm build        # 类型检查 + 构建
pnpm run budget   # 构建后查首屏体积
```
